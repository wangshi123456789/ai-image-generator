# ComfyUI Web应用

这是一个基于ComfyUI的Web应用，允许用户通过友好的界面使用ComfyUI的图像生成功能。

## 功能特点

- 简洁直观的用户界面
- 与ComfyUI后端的无缝集成
- 图像生成和处理功能
- 自定义工作流支持

## 安装与使用

1. 确保已安装ComfyUI并能正常运行
2. 克隆本仓库
3. 安装依赖：`npm install`
4. 启动应用：`npm start`
5. 在浏览器中访问：`http://localhost:3000`

## 技术栈

- 前端：HTML, CSS, JavaScript (React)
- 后端：Node.js, Express
- 图像处理：ComfyUI API
